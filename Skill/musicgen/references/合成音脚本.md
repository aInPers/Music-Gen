# 合成音脚本（`.synth.json`）

一件乐器不一定非得是采样音源。合成音脚本用**纯 JSON 描述音色**，不含可执行代码，
所以可以手写、由大模型生成、进版本管理，加载时也不会执行任意逻辑。

两个用途：

1. **替身**：某层音色在采样库里找不到（合成器、pad、电子 bass），用脚本更接近原曲；
2. **修补**：采样音色太亮/太闷/没有起音，用脚本重新捏一个，再用 `eq` 补差。

---

## 1. 最短可用脚本

```json
{
  "name": "my_pad",
  "oscillators": [{"wave": "saw", "detune": -7, "level": 0.5}]
}
```

除 `oscillators` 外全部字段可省。`"oscillators": ["saw"]` 也是合法简写。

---

## 2. 完整字段

```json
{
  "name": "air_pad",
  "label": "空气垫",
  "description": "宽立体声慢起音 pad，用于副歌铺底",
  "gain": 0.18,
  "oscillators": [
    {"wave": "saw", "detune": -9, "level": 0.5, "pan": -0.35},
    {"wave": "saw", "detune": 9,  "level": 0.5, "pan": 0.35}
  ],
  "sub": {"wave": "sine", "octave": -1, "level": 0.25},
  "noise": {"level": 0.02, "decay": 0.6},
  "amp":    {"attack": 0.65, "decay": 1.4, "sustain": 0.8, "release": 1.6},
  "filter": {"cutoff": 1400, "resonance": 1.0, "env": 700, "env_decay": 0.9, "keytrack": 0.4},
  "fm":     {"ratio": 2.0, "index": 0.3, "decay": 0.5},
  "vibrato":{"rate": 4.6, "depth": 6, "delay": 0.25},
  "max_harmonics": 32
}
```

### 2.1 顶层

| 字段 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| `name` | 文件名 | — | 脚本名，写进音轨/warnings |
| `label` / `description` | 空 | — | 仅注释用途 |
| `gain` | 0.22 | 0–1.5 | **每音符的绝对增益**；采样乐器量级 0.03–0.3，别写 1.0 |
| `oscillators` | `[{"wave":"sine"}]` | 1–8 个 | 主振荡器 |
| `sub` | 无 | 对象 | 低八度补 sub；`octave` 省略时自动 −1 |
| `noise` | 无 | `{level, decay}` | 起音噪声（气声、弓毛、拨片） |
| `amp` / `filter` / `fm` / `vibrato` | 见下 | 对象 | 包络与调制 |
| `max_harmonics` | 32 | 1–128 | 带限合成的最高谐波次数，控 CPU 与亮度 |

不认识的字段会**直接报错**（防止拼错键以为生效了）。

### 2.2 振荡器

| 字段 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| `wave` | `sine` | — | `sine` / `saw` / `square` / `triangle` / `noise`，可写中文（`锯齿`/`方波`/`三角`/`正弦`/`噪声`） |
| `octave` | 0 | −3–3 | 相对音高的八度偏移 |
| `detune` | 0 | −100–100 | 音分；两个振荡器 ±7–12 音分是经典的「宽」 |
| `level` | 1.0 | 0–4 | 相对音量 |
| `pan` | 0 | −1–1 | 单振荡器声像；左右各一可做出宽度 |
| `phase` | 0 | −1–1 | 起始相位（周期比例），多个同波振荡器错开相位可去相位堆叠 |

### 2.3 包络 `amp`

| 字段 | 默认 | 范围 | 听感 |
| --- | --- | --- | --- |
| `attack` | 0.01 | 0–8s | <0.02 打击/拨弦；0.15–0.4 弓弦；>0.5 pad |
| `decay` | 0.35 | 0–12s | 到 sustain 的时间 |
| `sustain` | 0.7 | 0–1.5 | 持续电平；0.8 以上接近风琴 |
| `release` | 0.6 | 0–12s | 松键后的尾音，受音符时值之外的额外长度限制 |

### 2.4 滤波 `filter`

| 字段 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| `cutoff` | 12000 | 40–20000 Hz | 基础截止频率 |
| `resonance` | 0.7 | 0.3–8 | 截止点共振，>2 有明显「哇」的音染 |
| `env` | 0 | 0–16000 Hz | 包络把截止最多推高多少（拨弦/铜管靠它做「亮→暗」） |
| `env_decay` | 0.4 | 0.01–8s | 包络回落速度 |
| `keytrack` | 0 | 0–1 | 1 = 截止跟随基频（高音更亮，接近真实乐器） |

### 2.5 调制

| 字段 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| `fm.ratio` | 2.0 | 0.25–16 | 调制器与载波频率比；整数比偏金属，非整数比偏钟 |
| `fm.index` | 0 | 0–8 | 调制深度；0.3–0.8 增加谐波，>2 明显失真 |
| `fm.decay` | 0.5 | 0.02–8s | FM 指数衰减（钟/电钢的「叮」） |
| `vibrato.rate` | 5.0 | 0.1–12 Hz | 颤音速率 |
| `vibrato.depth` | 0 | 0–100 音分 | >15 开始明显走音，人声/弦乐 5–12 |
| `vibrato.delay` | 0.2 | 0–3s | 起音后多久开始颤 |

## 3. 怎么挂到工程上

### 3.1 作为注册乐器（全局可用）

```bat
python -m musicgen instrument add airpad --name 空气垫 --synth air_pad --low 48 --high 96
python -m musicgen synth render air_pad -o output/airpad.wav --midi 60,64,67
```

之后工程里写 `instrument="airpad"` 即可，和采样乐器一样。`--synth` 也接受脚本路径，
相对路径按**注册表文件所在目录**解析（不是当前工作目录）。

### 3.2 挂在单条音轨上（推荐，工程自包含）

音轨文件：

```xml
<track name="Pad" instrument="synth" patch="../synths/air_pad.synth.json"
       gain="-7dB" pan="0.1" reverb="0.25">
  <note time="0" dur="4" pitch="C4,E4,G4" vel="0.6"/>
</track>
```

`patch` 相对**音轨文件**所在目录。脚本坏了在打开工程时就报错（退出码 2），
不会静默变声。

### 3.3 由 `analyze --decisions` 自动落盘

决策文件里写 `synth_patches`，`analyze` 会把脚本写到 `<工程目录>/synths/`，
音轨自动带上 `patch`。见 `references/逆向判断.md` §4。

## 4. 自检

```bat
:: 参数合法性 + 渲染一段试听
python -m musicgen synth check air_pad --midi 60 --dur 0.8
python -m musicgen synth render air_pad -o output/airpad.wav --midi 48,55,60,64

:: 从内置预设起步改，比从零写快
python -m musicgen synth new -o songs/MySong/synths/air.synth.json --preset warm_pad
```

`synth check` 会打印峰值与 RMS：**峰值 0.1–0.5** 是健康区间。太高会把总线推爆，
太低则要靠轨道 `gain` 补 20dB 以上，噪声也被一起放大。

## 5. 内置预设

| 预设 | 适合 | 特征 |
| --- | --- | --- |
| `warm_pad` | 铺底、弦垫 | 双锯齿微失谐、慢起音、低通 |
| `glass_bell` | 高音点缀、钟琴 | FM 为主、快衰减、亮 |
| `analog_lead` | 主旋律、solo | 锯齿 + 滤波包络、轻微颤音 |
| `deep_bass` | sub / 808 | 正弦 + 低八度 sub、极快起音 |
| `pluck_string` | 拨弦、琶音 | 三角 + 短衰减 + 高共振 |
| `soft_keys` | 电钢、键盘层 | 正弦叠 FM、中速衰减 |
| `air_texture` | 气声、氛围 | 高比例噪声 + 窄滤波 |

`python -m musicgen synth show <预设>` 看完整参数，`synth list` 看全部。

## 6. 常见错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| `gain` 写 1.0 | 单音就接近满刻度，多轨必削波 | 0.15–0.3；用 `synth check` 看峰值 |
| 字段名拼错（`attack_time`） | 载入报错「不认识的字段」 | 按 §2 的表写；报错信息里有字段名 |
| 波形写 `pulse` / `noise_white` | `PatchError: 未知波形` | 只能用 §2.2 的五种 |
| 所有振荡器 `pan: 0` | 声场挤在中间 | 左右各一，`pan ±0.3`，或后期用 `chorus` |
| 慢起音 pad 配 0.1s 的音符 | 还没起来就结束了 | 起音 < 音符时值的 1/3；或拉长时值 |
| 用脚本模仿真实独奏乐器 | 永远差一口气 | 独奏优先采样；脚本用于「电子/合成」层 |
