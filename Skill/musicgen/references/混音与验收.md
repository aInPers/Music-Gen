# 混音与验收

渲染只要几秒，问题都在参数上。这一篇给的是**基线值 + 判断标准 + 听感处方**，
所有数字都可以在 `examples/` 里找到来源。

## 1. 混音基线

先按角色给值，再凭听感微调。绝对值不重要，**轨道之间的差值**才重要。

| 角色 | 乐器 | `gain` | `pan` | `reverb` |
| --- | --- | --- | --- | --- |
| 主旋律 | 小提琴 | −3 ~ −1 | +0.20 | 0.33–0.38 |
| 主旋律 | 竖笛 | −2 ~ 0 | +0.10 | 0.28–0.32 |
| 主旋律 | 小号 | −7 ~ −5 | +0.25 | 0.35–0.42 |
| 主旋律 | 钢琴右手 | −3 | +0.15 | 0.30–0.34 |
| 和声 | 钢琴 | −6 ~ −4 | −0.10 | 0.26–0.30 |
| 和声 | 吉他 | −8 ~ −6 | −0.20 | 0.24–0.28 |
| 低音 | 大提琴 | −7 ~ −5 | −0.15 | 0.22–0.26 |
| 低音 | 钢琴左手 | −6 ~ −4 | 0 | 0.08–0.12 |
| 节奏 | 鼓组 | −2 ~ 0 | 0 | 0.10–0.15 |
| 循环音型 | 钢琴 / 吉他 | −7 ~ −4 | ±0.25 | 0.16–0.22 |

规则：

- 旋律比伴奏高 **3dB 以上**；低音比旋律低 **3–5dB**。
- 同族乐器（两轨钢琴）靠 `pan` 分开：和声 −0.1、旋律 +0.15。
- 鼓的混响永远最小（0.1–0.15），加多了会糊成一团。
- 循环音型放两侧（±0.25），把中间让给旋律与低音。

## 2. 声像布局

```
左 −1.0        −0.5        0        +0.5        +1.0 右
   吉他/循环     和声     低音/鼓     旋律        小提琴/小号
```

- **低频居中**：大提琴、钢琴左手、底鼓都放 0 或接近 0，偏了会一只耳朵发闷。
- **旋律略偏**：+0.15 到 +0.25，比正中更有存在感，也不会和低音抢中间。
- **对称**：左侧有吉他，右侧就给小提琴或竖笛，否则整首偏一边。
- 独奏钢琴不需要拉开：左手 −0.08、右手 +0.12 足够。

## 3. 混响

`reverb` 是发送量，湿声 = 干声 × `reverb` × 0.9，脉冲响应是合成的，0.55–2.45 秒。

| 场景 | reverb | 听感 |
| --- | --- | --- |
| 近场 / 流行 | 0.10–0.18 | 干、贴脸、清楚 |
| 室内乐 / 民谣 | 0.22–0.30 | 有小房间感，最通用 |
| 抒情 / 电影 | 0.32–0.42 | 明显空间，旋律更「远」 |
| 大厅 / 史诗 | 0.45–0.55 | 宏大，但超过 0.5 容易糊 |
| 鼓 | 0.10–0.15 | 只要一点房间感 |

同一首曲子里，混响量要按「远近」分层：旋律最湿、低音最干、鼓最干。

### 3.1 用返回总线做混响（推荐给多轨）

逐轨 `reverb` 用的是同一个合成脉冲响应，够用但没法分别控制「空间大小」。给整首曲子统一空间感时，
建一条返回总线更干净：

```xml
<bus name="Reverb" gain="-5dB">
  <effect type="reverb" size="0.65" decay="3.2" predelay="28" mix="1"/>
</bus>
```

```xml
<track name="Piano" instrument="piano" bus="Music">
  <send bus="Reverb" amount="0.28"/>
</track>
```

* 送进去的是**已加过轨道推子的信号**（post-fader），所以推子拉低时混响也同比减少。
* 返回总线的 `reverb` 必须 `mix=1`：总线里只有湿声，干声已经在主路径上了。
* 不同轨用不同 `send` 量就能排出远近，不必给每条轨单独改 `reverb`。
* 延迟同理：再来一条 `Delay` 总线，`echo` 的 `mix` 给 0.3–0.5，轨道上 `send` 0.1–0.2。

## 4. 效果链（可选）

`reverb` 解决「空间」，效果链解决「个性」。二十个效果各有分工：

| 想要的效果 | 用哪个 | 建议参数 | 注意 |
| --- | --- | --- | --- |
| 声场太窄、乐器挤在中间 | `stereo` | `width` 1.4–1.8；需要更分明再加 `haas` 8–15ms | 单声道素材不会变小声；`width` 超过 1.8 侧信号会虚 |
| 旋律想要空间与余韵 | `echo` | `time` 300–450ms（抒情可 1/4 拍 = 60000/BPM 毫秒）、`feedback` 0.2–0.35、`mix` 0.15–0.3 | 回声尾巴受 `length` 限制，需要就加 `tail` |
| 前奏渐入 / 收尾渐弱 | `fade` | `in` 1–2s、`out` 2–3s、`curve` expo | 按该轨实际发声区间算，不会淡一整首 |
| 想要电子 / 机器人音色 | `electro` | `rate` 12–30Hz、`depth` 0.4–0.7、`bits` 8–10、`mix` 0.3–0.6 | `mix` 别给满，干声留一点才不刺耳 |
| 复古游戏 / 芯片音 | `8bit` | 默认即可；想更脏把 `rate` 降到 6000–8000 | 只给 1 条主旋律或色彩层用，铺满会刺耳 |
| 老采样器 / 低传真 | `4bit` | `tone` 0.5–0.7、`mix` 0.5–0.8 | `mix` 留一点干声，能保住原始音头 |
| 故意破坏、噪声化 | `2bit` | `rate` 2000–4000、`mix` 0.3–0.6 | 极端音色，只适合短小的点缀或过门 |
| 音色偏亮/偏闷、和原曲差一截 | `eq` | `low` / `high` 按差值的**同向**补，单次 ≤6dB | 超过 6dB 说明音色选错，换乐器而不是硬掰 |
| 合成器太干净、缺谐波 | `drive` | `amount` 0.15–0.35、`tone` 0.5–0.7、`mix` 0.5–0.8 | 给贝斯/lead 用；鼓上少用，会糊 |
| 动态太大、安静段听不见 | `compressor` | `threshold` −22~−16dB、`ratio` 3–4、`release` 150–250ms | 只在峰值因数 <9dB 时加；整体已很扁就别再压 |
| 单薄、想要宽度 | `chorus` | `rate` 0.4–0.8Hz、`depth` 4–8ms、`mix` 0.25–0.4 | 左右反相调制；主唱/贝斯慎用（会虚） |
| 太亮、太近、想推远 | `filter` | `mode` lowpass、`freq` 2500–5000Hz；要闷一点再降到 1200 | 扫频用 `lfo_rate` 0.3–1Hz + `lfo_depth` 0.5–1.5 |
| 想要呼吸感／老电钢 | `tremolo` | `rate` 3–6Hz、`depth` 0.2–0.5；左右错开用 `stereo` 0.5 | `rate` 超过 8Hz 会变成粗糙的调幅声 |
| 铺底太死、想流动 | `autopan` | `rate` 0.1–0.4Hz、`depth` 0.5–0.8 | 只给铺底/琶音；旋律和低频不要加 |
| 想要喷气式扫频 | `flanger` | `rate` 0.2–0.6Hz、`depth` 2–4ms、`feedback` 0.4–0.6 | `feedback` 超过 0.7 会啸叫 |
| 比镶边更柔的流动 | `phaser` | `rate` 0.3–0.8Hz、`stages` 4–6、`mix` 0.4–0.6 | 和 `chorus` 二选一，别叠加 |
| 复古暖色、轻微走带 | `tape` | `drive` 0.2–0.4、`tone` 0.5–0.65、`wow` 0.1–0.3、`flutter` 0.1 | `wow` 超过 0.5 会明显跑调 |
| 母带压住瞬态 | `limiter` | `ceiling` −1、`release` 60–100ms、`lookahead` 4–6ms | 放 `<master>` 或总线末级；别叠两个 |
| 底噪大、拖尾长 | `gate` | `threshold` 比最弱音符低 6–10dB、`release` 80–150ms | 阈值过高会把弱音切掉 |
| 需要统一空间感 | `reverb` | 返回总线 `mix=1`；挂在轨上 0.2–0.35 | 与轨道 `reverb` 二选一，别两套叠满 |

原则：

* **效果是插入式的**，按音轨 XML 里的顺序串联；同一条轨 2–3 个足够，堆 4 个以上容易糊。
* **先混干声再考虑效果**：`gain`/`pan`/`reverb` 摆不平的，加效果也救不回来。
* 不要给所有轨都加 `echo`：低频和鼓加延迟会拖拍，通常只给旋律或色彩层。
* `electro` 会改变音色本身，独奏、间奏点缀比整首铺满更耐听。

### 4.1 总线混音工作流

多轨曲子（4 轨以上）按这个顺序搭，比逐轨堆效果稳：

```
音轨（gain / pan / 轨道效果）
   ├─→ Drums 总线：compressor（threshold −20、ratio 3–4）→ 可选 tape
   ├─→ Music 总线：eq（±3dB 内）→ stereo（width 1.2–1.4）
   ├─→ send → Reverb 总线：reverb mix=1
   ├─→ send → Delay 总线：echo mix=0.3–0.5 → 可选 filter
   └────────────────────────────────→ 母带：limiter（ceiling −1）
```

* **鼓组总线压缩**比逐轨压更整齐：几件鼓一起进来，压缩器按整体峰值动作，节奏感更紧。
* **音乐总线 EQ** 只做整体微调（±3dB），单件乐器的音色问题回轨道上解决。
* **返回总线**只放湿声（`mix=1`），用轨道 `send` 量排远近。
* **母带限制器**放 `<master>` 里，`ceiling=-1`；`normalize` 保持 true。
* 总线推子先归零，用轨道 `gain` 摆平衡；最后再用总线推子整体压一点。
* 别把同一条轨同时挂逐轨 `reverb` 和送进混响总线——两套空间叠在一起会糊。

参数起点（直接可用）：

```xml
<bus name="Drums" gain="-1dB">
  <effect type="compressor" threshold="-20" ratio="3.5" release="140" makeup="2"/>
</bus>
<bus name="Music" gain="-2dB">
  <effect type="eq" low="1.5" mid="-1" high="1.2" mid_freq="800"/>
  <effect type="stereo" width="1.25"/>
</bus>
<bus name="Reverb" gain="-5dB">
  <effect type="reverb" size="0.65" decay="3.2" tone="0.5" predelay="28" mix="1"/>
</bus>
<master>
  <effect type="limiter" ceiling="-1" release="80" lookahead="5"/>
</master>
```

完整可跑例子见仓库 `examples/mixbus`。

## 5. 母带与位深

| 项 | 建议 | 说明 |
| --- | --- | --- |
| `normalize` | true（默认） | 峰值归一到 −1dBFS；多轨叠加不会削波 |
| `masterGain` | −1dB | 与归一化配合，留 1dB 余量 |
| 位深 | 24bit（默认） | 归档、继续处理 |
| 位深 | 16bit | 分享、发微信；加 `--bits 16` |
| 位深 | 32bit float | 还要进别的软件混音；`--float32` |
| 采样率 | 44100 | 视频/播客通用；48000 用于视频工程 |

注意：归一化只看峰值，不看响度。**稀疏的独奏和满编制乐队都会到 −1dBFS，
但 RMS 差很多**——不要用 RMS 跨曲比较「谁更响」。

## 6. 渲染输出怎么读

```bash
python -m musicgen render songs/demo/demo.musicproj -o output/demo.wav
```

```
渲染 Skill Demo → output\demo.wav
  3 条音轨 | 96BPM | 44100Hz | 时长 0:21.50
完成：output\demo.wav
  时长 0:21.50 | 峰值 -1.0dBFS | RMS -19.8dBFS | 5.4MB | 位深 24
  音符事件 61 个 | 耗时 1.4s (15.8× 实时)
    · Chords [piano] 音符 32 峰值 0.269
    · Melody [piano] 音符 21 峰值 0.550
    · Cello [cello] 音符 8 峰值 0.136
```

| 字段 | 怎么判断 |
| --- | --- |
| 时长 | 与目标差 < 1 秒；差 2 秒多半是 `tail` 没算 |
| 峰值 | 归一化开着恒为 −1.0dBFS；不是就说明关了归一化或有异常 |
| RMS | 独奏钢琴 −22 ~ −18；小编制 −20 ~ −16；满编制 −16 ~ −12 |
| 音符事件 | 太少（< 预期一半）说明有轨没写进去 |
| 每轨峰值 | 0 = 空轨/静音；旋律应 0.5–0.8，伴奏 0.2–0.4，低音 0.15–0.3 |

`!` 开头的行是警告，不是错误，但**必须处理**，尤其是音域越界（会换合成器）。

## 7. 验收清单

交付前逐条过，任一条不过就回去改：

1. `validate` 退出码 0，没有「超出循环周期」。
2. `render` 退出码 0，没有 `!` 警告。
3. 时长与目标差 < 1 秒（要精确就写 `length`）。
4. 峰值 −1.0 ± 0.2 dBFS。
5. 每条轨的峰值都 > 0（没有空轨）。
6. 开头 1 秒内能听到东西，结尾有余韵，不是硬切。
7. 旋律音区高于伴奏，且能听清（把伴奏轨 mute 对比一下）。
8. 低音与鼓不同时糊在 C2 附近。

## 8. 听感问题 → 处方

| 症状 | 多半是 | 改法 |
| --- | --- | --- |
| 整体发糊 | `reverb` > 0.45，或低音区堆了两件乐器 | 混响降到 0.3；大提琴上移八度或钢琴左手让位 |
| 太干、像 MIDI | `reverb` < 0.15，力度全一样 | 混响 0.25–0.32；按 p/mp/mf/f 分层 |
| 太吵、没有焦点 | 轨数多且都在 0dB，或全在 C5 | 每轨按基线降 3–6dB；只留一条旋律，其余改长音 |
| 低频轰 | 钢琴左手、大提琴、底鼓同时动 | 左手改 C3–C4；大提琴只走根音；底鼓降到 0.8 |
| 旋律被埋 | 旋律与伴奏同音区、同节奏 | 旋律升八度；伴奏改切分或减少音符 |
| 结尾突然 | `length` 卡在小节线，最后一音太短 | 最后一音 `dur=4`；用 `length="auto"` + `tail="2s"` |
| 动态平 | 全曲 vel 都在 0.6–0.7 | 前奏 0.35、副歌 0.8；每段整体错开 0.1 |
| 像循环播放 | A 段重复没变化 | 第二遍换乐器/加八度/加鼓，或改 `pan` |
| 声像偏一边 | 只有左侧有吉他 | 右侧补小提琴或竖笛，或把吉他移到 −0.15 |

## 9. 三套现成混音

### 9.1 独奏钢琴

| 轨 | gain | pan | reverb |
| --- | --- | --- | --- |
| 左手（低音+和声） | −5dB | −0.08 | 0.26 |
| 右手（旋律） | −3dB | +0.12 | 0.32 |

母带 `masterGain="-1dB"`，归一化开。适合抒情、Lo-fi、极简。

### 9.2 钢琴三重奏

| 轨 | gain | pan | reverb |
| --- | --- | --- | --- |
| 钢琴（和声） | −6dB | −0.10 | 0.30 |
| 小提琴（旋律） | −3dB | +0.20 | 0.35 |
| 大提琴（低音） | −6dB | −0.15 | 0.26 |

小提琴比钢琴高 3dB，大提琴压到和钢琴齐平——弦乐本身电平高，容易盖住钢琴。

### 9.3 民谣乐队

| 轨 | gain | pan | reverb |
| --- | --- | --- | --- |
| 吉他（扫弦） | −7dB | −0.20 | 0.26 |
| 竖笛（旋律） | −2dB | +0.10 | 0.30 |
| 鼓组 | 0dB | 0 | 0.12 |

鼓最响但不加混响；竖笛只比鼓低 2dB，否则会被扫弦埋掉。

## 10. 不要做

- **不要用 `masterGain` 当总音量**：它只影响母带，归一化后又被拉回 −1dBFS，等于没改。
- **不要给鼓加 0.4 混响**：底鼓会拖尾，整首变糊。
- **不要所有轨都 −3dB**：差值没了，等于没混音。
- **不要靠 RMS 判断响度**：归一化按峰值走，RMS 只是密度。
- **不要在 `length="auto"` 时追求精确秒数**：`tail` 默认 2 秒，一定对不上。
