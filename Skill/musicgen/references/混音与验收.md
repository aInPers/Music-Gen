# 混音与验收

渲染只要几秒，问题都在参数上。这一篇给的是**基线值 + 判断标准 + 听感处方**，
所有数字都可以在 `examples/` 里找到来源。

## 1. 混音基线

先按角色给值，再凭听感微调。绝对值不重要，**轨道之间的差值**才重要。

| 角色 | 乐器 | `gain` | `pan` | `reverb` |
| --- | --- | --- | --- | --- |
| 主旋律 | 小提琴 | −3 ~ −1 | +0.20 | 0.33–0.38 |
| 主旋律 | 竖笛 | −2 ~ 0 | +0.10 | 0.28–0.32 |
| 主旋律 | 小号 | −7 ~ −5 | +0.25 | 0.35–0.42 |
| 主旋律 | 钢琴右手 | −3 | +0.15 | 0.30–0.34 |
| 和声 | 钢琴 | −6 ~ −4 | −0.10 | 0.26–0.30 |
| 和声 | 吉他 | −8 ~ −6 | −0.20 | 0.24–0.28 |
| 低音 | 大提琴 | −7 ~ −5 | −0.15 | 0.22–0.26 |
| 低音 | 钢琴左手 | −6 ~ −4 | 0 | 0.08–0.12 |
| 节奏 | 鼓组 | −2 ~ 0 | 0 | 0.10–0.15 |
| 循环音型 | 钢琴 / 吉他 | −7 ~ −4 | ±0.25 | 0.16–0.22 |

规则：

- 旋律比伴奏高 **3dB 以上**；低音比旋律低 **3–5dB**。
- 同族乐器（两轨钢琴）靠 `pan` 分开：和声 −0.1、旋律 +0.15。
- 鼓的混响永远最小（0.1–0.15），加多了会糊成一团。
- 循环音型放两侧（±0.25），把中间让给旋律与低音。

## 2. 声像布局

```
左 −1.0        −0.5        0        +0.5        +1.0 右
   吉他/循环     和声     低音/鼓     旋律        小提琴/小号
```

- **低频居中**：大提琴、钢琴左手、底鼓都放 0 或接近 0，偏了会一只耳朵发闷。
- **旋律略偏**：+0.15 到 +0.25，比正中更有存在感，也不会和低音抢中间。
- **对称**：左侧有吉他，右侧就给小提琴或竖笛，否则整首偏一边。
- 独奏钢琴不需要拉开：左手 −0.08、右手 +0.12 足够。

## 3. 混响

`reverb` 是发送量，湿声 = 干声 × `reverb` × 0.9，脉冲响应是合成的，0.55–2.45 秒。

| 场景 | reverb | 听感 |
| --- | --- | --- |
| 近场 / 流行 | 0.10–0.18 | 干、贴脸、清楚 |
| 室内乐 / 民谣 | 0.22–0.30 | 有小房间感，最通用 |
| 抒情 / 电影 | 0.32–0.42 | 明显空间，旋律更「远」 |
| 大厅 / 史诗 | 0.45–0.55 | 宏大，但超过 0.5 容易糊 |
| 鼓 | 0.10–0.15 | 只要一点房间感 |

同一首曲子里，混响量要按「远近」分层：旋律最湿、低音最干、鼓最干。

## 4. 母带与位深

| 项 | 建议 | 说明 |
| --- | --- | --- |
| `normalize` | true（默认） | 峰值归一到 −1dBFS；多轨叠加不会削波 |
| `masterGain` | −1dB | 与归一化配合，留 1dB 余量 |
| 位深 | 24bit（默认） | 归档、继续处理 |
| 位深 | 16bit | 分享、发微信；加 `--bits 16` |
| 位深 | 32bit float | 还要进别的软件混音；`--float32` |
| 采样率 | 44100 | 视频/播客通用；48000 用于视频工程 |

注意：归一化只看峰值，不看响度。**稀疏的独奏和满编制乐队都会到 −1dBFS，
但 RMS 差很多**——不要用 RMS 跨曲比较「谁更响」。

## 5. 渲染输出怎么读

```bash
python -m musicgen render songs/demo/demo.musicproj -o output/demo.wav
```

```
渲染 Skill Demo → output\demo.wav
  3 条音轨 | 96BPM | 44100Hz | 时长 0:21.50
完成：output\demo.wav
  时长 0:21.50 | 峰值 -1.0dBFS | RMS -19.8dBFS | 5.4MB | 位深 24
  音符事件 61 个 | 耗时 1.4s (15.8× 实时)
    · Chords [piano] 音符 32 峰值 0.269
    · Melody [piano] 音符 21 峰值 0.550
    · Cello [cello] 音符 8 峰值 0.136
```

| 字段 | 怎么判断 |
| --- | --- |
| 时长 | 与目标差 < 1 秒；差 2 秒多半是 `tail` 没算 |
| 峰值 | 归一化开着恒为 −1.0dBFS；不是就说明关了归一化或有异常 |
| RMS | 独奏钢琴 −22 ~ −18；小编制 −20 ~ −16；满编制 −16 ~ −12 |
| 音符事件 | 太少（< 预期一半）说明有轨没写进去 |
| 每轨峰值 | 0 = 空轨/静音；旋律应 0.5–0.8，伴奏 0.2–0.4，低音 0.15–0.3 |

`!` 开头的行是警告，不是错误，但**必须处理**，尤其是音域越界（会换合成器）。

## 6. 验收清单

交付前逐条过，任一条不过就回去改：

1. `validate` 退出码 0，没有「超出循环周期」。
2. `render` 退出码 0，没有 `!` 警告。
3. 时长与目标差 < 1 秒（要精确就写 `length`）。
4. 峰值 −1.0 ± 0.2 dBFS。
5. 每条轨的峰值都 > 0（没有空轨）。
6. 开头 1 秒内能听到东西，结尾有余韵，不是硬切。
7. 旋律音区高于伴奏，且能听清（把伴奏轨 mute 对比一下）。
8. 低音与鼓不同时糊在 C2 附近。

## 7. 听感问题 → 处方

| 症状 | 多半是 | 改法 |
| --- | --- | --- |
| 整体发糊 | `reverb` > 0.45，或低音区堆了两件乐器 | 混响降到 0.3；大提琴上移八度或钢琴左手让位 |
| 太干、像 MIDI | `reverb` < 0.15，力度全一样 | 混响 0.25–0.32；按 p/mp/mf/f 分层 |
| 太吵、没有焦点 | 轨数多且都在 0dB，或全在 C5 | 每轨按基线降 3–6dB；只留一条旋律，其余改长音 |
| 低频轰 | 钢琴左手、大提琴、底鼓同时动 | 左手改 C3–C4；大提琴只走根音；底鼓降到 0.8 |
| 旋律被埋 | 旋律与伴奏同音区、同节奏 | 旋律升八度；伴奏改切分或减少音符 |
| 结尾突然 | `length` 卡在小节线，最后一音太短 | 最后一音 `dur=4`；用 `length="auto"` + `tail="2s"` |
| 动态平 | 全曲 vel 都在 0.6–0.7 | 前奏 0.35、副歌 0.8；每段整体错开 0.1 |
| 像循环播放 | A 段重复没变化 | 第二遍换乐器/加八度/加鼓，或改 `pan` |
| 声像偏一边 | 只有左侧有吉他 | 右侧补小提琴或竖笛，或把吉他移到 −0.15 |

## 8. 三套现成混音

### 8.1 独奏钢琴

| 轨 | gain | pan | reverb |
| --- | --- | --- | --- |
| 左手（低音+和声） | −5dB | −0.08 | 0.26 |
| 右手（旋律） | −3dB | +0.12 | 0.32 |

母带 `masterGain="-1dB"`，归一化开。适合抒情、Lo-fi、极简。

### 8.2 钢琴三重奏

| 轨 | gain | pan | reverb |
| --- | --- | --- | --- |
| 钢琴（和声） | −6dB | −0.10 | 0.30 |
| 小提琴（旋律） | −3dB | +0.20 | 0.35 |
| 大提琴（低音） | −6dB | −0.15 | 0.26 |

小提琴比钢琴高 3dB，大提琴压到和钢琴齐平——弦乐本身电平高，容易盖住钢琴。

### 8.3 民谣乐队

| 轨 | gain | pan | reverb |
| --- | --- | --- | --- |
| 吉他（扫弦） | −7dB | −0.20 | 0.26 |
| 竖笛（旋律） | −2dB | +0.10 | 0.30 |
| 鼓组 | 0dB | 0 | 0.12 |

鼓最响但不加混响；竖笛只比鼓低 2dB，否则会被扫弦埋掉。

## 9. 不要做

- **不要用 `masterGain` 当总音量**：它只影响母带，归一化后又被拉回 −1dBFS，等于没改。
- **不要给鼓加 0.4 混响**：底鼓会拖尾，整首变糊。
- **不要所有轨都 −3dB**：差值没了，等于没混音。
- **不要靠 RMS 判断响度**：归一化按峰值走，RMS 只是密度。
- **不要在 `length="auto"` 时追求精确秒数**：`tail` 默认 2 秒，一定对不上。
