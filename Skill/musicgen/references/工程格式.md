# 工程格式速查

写 `*.musicproj` 和 `*.track.xml` 之前看这一篇。全部字段与仓库 `docs/项目文档.md` 第 5–7 节一致。

## 1. 文件结构

```
songs/<slug>/
├─ <slug>.musicproj          工程：全局参数 + 每条音轨的引用
└─ tracks/
   ├─ melody.track.xml       音轨：乐器 + 混音参数 + 音符
   ├─ chords.track.xml
   └─ drums.track.xml
```

- 一个音轨一个文件，路径**相对工程目录**（不是当前工作目录）。
- 全部 UTF-8 编码。`&` 写 `&amp;`，注释里不能出现 `--`。
- `length="auto"` 的工程，渲染时长由最晚结束的音符决定。

## 2. 最小可跑模板（已验证：8 小节 / 21.5 秒）

```xml
<musicproj name="Skill Demo" bpm="96" sampleRate="44100" beatsPerBar="4"
           length="auto" tail="1.5s" masterGain="-1dB" normalize="true">
  <track file="tracks/chords.track.xml"/>
  <track file="tracks/melody.track.xml"/>
  <track file="tracks/cello.track.xml"/>
</musicproj>
```

## 3. `<musicproj>` 属性

| 属性 | 默认 | 说明 |
| --- | --- | --- |
| `name` | 文件名 | 工程名，显示在渲染摘要里 |
| `bpm` | 120 | 全局速度，5–600 |
| `sampleRate` | 44100 | 推荐 44100 / 48000 |
| `beatsPerBar` | 4 | 每小节拍数；3 就是 3/4 拍 |
| `length` | auto | 见 §7；可写拍数、`8s`、`500ms`、`4bar` |
| `tail` | 2s | 只在 `length="auto"` 时追加的余韵，`0` = 不追加 |
| `masterGain` | 0dB | 母带增益，`-1dB` / `+1.5dB` |
| `normalize` | true | 峰值归一到 −1dBFS；false 只做削波保护 |

## 4. `<track>` 引用（工程层）

```xml
<track file="tracks/melody.track.xml" gain="-3dB" pan="0.15"/>
```

| 可覆盖属性 | 说明 |
| --- | --- |
| `name` / `gain` / `pan` / `mute` / `solo` / `loop` | 覆盖音轨文件里的同名值 |
| **`reverb` 不在此列** | 写在工程层不生效，必须写进音轨文件 |

`file` 必填，相对工程目录。GUI 保存或 `track edit` 改过参数后，会自动删掉工程层的同名覆盖，
避免下次载入被旧值盖回去。

## 5. 音轨文件 `<track>`

```xml
<track name="Melody" instrument="piano" gain="-3dB" pan="0.16"
       reverb="0.32" bpm="84" transpose="0">
  <note time="0" dur="0.5" pitch="E5" vel="0.78"/>
</track>
```

| 属性 | 默认 | 说明 |
| --- | --- | --- |
| `name` | 文件名 | 音轨名 |
| `instrument` | piano | 注册键或中文名：`piano` `violin` `cello` `trumpet` `recorder` `guitar` `drums`（`钢琴` `小提琴` `大提琴` `小号` `竖笛` `吉他` `架子鼓`） |
| `bpm` | 跟随工程 | 逐轨速度；音符按本轨 BPM 换算 |
| `gain` | 0dB | 音量，`-6dB` / `+2` / `0` |
| `pan` | 0 | −1 全左 … +1 全右，等功率 |
| `reverb` | 0 | 0–1，混响发送量；室内 0.25–0.4，大厅 0.5+ |
| `loop` | false | 循环轨，见 §7 |
| `loopLen` | 自动 | 循环周期（拍），不给就向上取整到整小节 |
| `loopCount` | 0 | 循环次数；0 = 一直循环到工程结束 |
| `mute` / `solo` | false | 静音 / 独奏；有 solo 时只渲染 solo 轨 |
| `transpose` | 0 | 整体移调半音，−48…+48；移调后越界会退回合成器 |

### 5.1 效果链 `<effect>`

写在音符**前面**，按出现顺序串联，处理位置在声像之后、汇入母线之前：

```xml
<track name="Guitar" instrument="guitar" gain="-4dB" pan="0.1" reverb="0.2">
  <effect type="echo" time="375" feedback="0.3" mix="0.22"/>
  <effect type="stereo" width="1.6"/>
  <effect type="fade" in="1.5" out="2.5"/>
  <effect type="electro" rate="18" depth="0.6" bits="10" mix="0.5"/>
  <note time="0" dur="1" pitch="E2" vel="0.7"/>
</track>
```

| 类型 | 中文 | 参数（默认） | 什么时候用 |
| --- | --- | --- | --- |
| `stereo` | 立体 | `width` 1.6 · `haas` 0ms · `mix` 1 | 声场太窄、想拉开层次；单声道素材不会被弄小声 |
| `echo` | 回声 | `time` 320ms · `feedback` 0.36 · `tone` 0.5 · `pingpong` 开 · `mix` 0.3 | 旋律点缀、空间感；`tone` 越小越闷 |
| `fade` | 淡入淡出 | `in` 0.8s · `out` 1.5s · `curve` expo | 前奏渐入、收尾；按该轨实际发声区间计算 |
| `electro` | 电音 | `rate` 30Hz · `depth` 0.8 · `drive` 0.35 · `bits` 8 · `mix` 0.85 | 电子 / 机器人音色；`rate` 低是颤音、高是金属环调 |
| `8bit` | 8bit | `rate` 11025Hz · `tone` 0.75 · `drive` 0 · `mix` 1 | 红白机颗粒感；8 位（256 级）+ 11kHz 降采样 |
| `4bit` | 4bit | `rate` 8000Hz · `tone` 0.6 · `drive` 0 · `mix` 1 | 早期采样器的粗糙感；16 级电平 |
| `2bit` | 2bit | `rate` 4000Hz · `tone` 0.45 · `drive` 0 · `mix` 1 | 极端破坏，几乎只剩方波；4 级电平 |

规则：

* **只写要改的参数**，其余用默认值；单位可省（`time="450"` 与 `"450ms"` 等价）。
* 未知类型 / 未知参数 → 警告并跳过，不中断渲染；数值越界 → 夹到范围内。
* **顺序即信号流**：`回声 → 立体` 与 `立体 → 回声` 不同，`fade` 放在链尾。
* 回声尾巴受工程长度限制：超出 `length` 的部分会被截掉，需要余韵就加 `tail`。
* 别给所有音轨都堆 `echo` / `electro`：1–2 条轨用就够，全堆会糊。
* `8bit` / `4bit` / `2bit` 的位深固定，只能调 `rate`（越低越破）、`tone`（越小越闷）、`drive`（加失真）；按素材自身峰值量化，插入后轨道响度不变。

## 6. 音符 `<note>`

| 属性 | 必填 | 说明 |
| --- | --- | --- |
| `time` | 否 | 起始位置（拍，从 0 开始）；**省略 = 接上一个音的结尾**，多声部不要省 |
| `dur` | 是 | 时值（拍），必须 > 0 |
| `pitch` | 是 | 音名或鼓件名；逗号分隔即和弦 |
| `vel` | 否 | 0–1 小数，或 1–127 整数；默认 0.8 |

### 6.1 时值写法

| 写法 | 含义 |
| --- | --- |
| `1/4` | 四分之一拍（十六分音符） |
| `1/2` | 半拍（八分音符） |
| `1` | 一拍（四分音符） |
| `2` | 两拍（二分音符） |
| `4` | 四拍（全音符，4/4 一小节） |
| `1/3` | 三连音；任意分母都行，内部用精确分数，不累积浮点误差 |
| `2*4` | 8 拍（两小节），乘法写法 |
| `0.5` | 半拍，小数也认 |

### 6.2 音名

科学音高记法：`C4` = 中央 C = MIDI 60。支持 `C#4`、`Db4`、`C♯4`、`D♭4`，也认纯数字 `60`。

```xml
<note time="0" dur="2" pitch="C4,E4,G4" vel="0.6"/>   <!-- C 大三和弦 -->
```

### 6.3 鼓件名

`instrument="drums"` 时 `pitch` 直接写鼓件，逗号可叠加：

| 写法 | 鼓件 | 写法 | 鼓件 |
| --- | --- | --- | --- |
| `kick` | 底鼓 | `hat` | 闭镲 |
| `snare` | 军鼓 | `openhat` | 开镲 |
| `rim` | 边击 | `pedalhat` | 踏镲 |
| `clap` | 拍手 | `crash` | 吊镲 |
| `tom1` / `tom2` | 高/中音嗵鼓 | `ride` | 叮叮镲 |
| `floor` | 落地嗵鼓 | `bell` | 镲帽 |
| `tamb` / `cowbell` / `shaker` | 铃鼓 / 牛铃 / 沙锤 | `底鼓` `军鼓` 等中文名 | 等价 |

鼓的 `dur` 只是占位，不控制长度：底鼓极短、开镲 1.9s、吊镲 2.5s。

## 7. 时长与循环

### 7.1 `length`

- `length="32"` → 32 拍；`length="8s"`、`"500ms"`、`"4bar"` 等价写法。
- `length="auto"`（默认）→ 所有**非无限循环轨**里最晚的结束时间 + `tail`。
- 全部是无限循环轨 → 按 4 小节 + `tail` 计算。
- 要精确秒数（比如正好 30 秒）就写 `length="30s"`，别靠 auto + tail 猜。

### 7.2 循环

```
周期 = loopLen（给了就用）
     = ceil(内容长度 / beatsPerBar) * beatsPerBar（没给，至少 1 小节）
```

- `loopCount=0` 一直重复到工程结束；`loopCount=N` 只重复 N 次。
- 音符起点 ≥ 周期时**不会被播放**，`validate` 会给警告。
- 音符可以越过周期边界继续发声（钢琴延音本该如此），不做切断。
- 循环只是「重新触发同样的音符」，没有时间拉伸。

```xml
<track name="Ostinato" instrument="piano" loop="true" loopLen="4">
  <note time="0" dur="1" pitch="C3" vel="0.4"/>
  <note time="1" dur="1" pitch="G3" vel="0.34"/>
  <note time="2" dur="1" pitch="E4" vel="0.36"/>
  <note time="3" dur="1" pitch="G3" vel="0.34"/>
</track>
```

## 9. 校验与报错

```bash
python -m musicgen validate songs/<slug>/<slug>.musicproj
```

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| `文件不存在` | 路径错，或相对路径基准不对 | 先 `cd /f/Music-Gen`（cmd 用 `cd /d F:\Music-Gen`） |
| `XML 解析失败: not well-formed` | 标签没闭合、引号缺失、`&` 没转义 | 按行列号修 |
| `音轨文件不存在: tracks/x.track.xml` | `file` 相对的是**工程目录** | 改对相对路径 |
| `无法识别的音名: H9` | 音名拼错 | `C4` / `C#4` / `Db4` / `60` |
| `dur 必须大于 0` | 时值 0 或负 | 至少 `1/16` |
| `bpm 超出合理范围 5-600` | 速度写错 | 改范围 |
| `工程里没有任何 <track>` | 没引用任何音轨 | 加 `<track file="…"/>` |
| `N 个音符起点超出循环周期 X 拍` | `loopLen` 太短 | 加大 `loopLen` 或挪音符 |

渲染期的 `!` 警告（`validate` 不报）：

| 提示 | 处理 |
| --- | --- |
| `乐器 'x' 的采样音域为 …，B1 超出范围，该音改用内置合成器` | 换八度或换乐器 |
| `未注册的乐器 'x'，使用内置合成器` | 改成七件之一 |
| `没有可渲染的音轨（全部静音或为空）` | 检查 `mute` / `solo` / 空轨 |

## 10. 反模式

- **用 `note add` 循环 100 次**搭建整首曲子：慢且容易错位。整段用 XML 一次写，CLI 只用来微调。
- **所有轨都 0dB**：叠加后靠归一化压下来，动态全平。按 `references/混音与验收.md` 的基线给差值。
- **省略 `time`**：单声部还行，多声部必然错位。一律显式写。
- **和弦拆成三个独立音**：行数翻三倍，还容易漏掉其中一个。
- **全曲 16 分音符铺满**：所有轨都在动 = 没有焦点。留白比加音符更有效。
- **复制粘贴不做变化**：A 段重复时换配器、加高八度、改力度，否则听起来像循环播放。
- **忘记 `tail`**：`length="auto"` 默认会多 2 秒，验收时对不上目标时长。
